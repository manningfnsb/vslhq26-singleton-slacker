# Municipal Data Center Security & Operations - Compliance Response
# Submitted by: Northern Shield Technologies

## Section 1: Physical Security

REQ-001 Response: Our facility maintains 24/7 security with two guards per shift. Patrol schedules are documented in our Physical Security Plan (PSP-2026-03) with randomized routes verified by guard tour system.

REQ-002 Response: All entry points use HID iCLASS SE readers (badge) combined with iris recognition biometric scanners. Dual-factor is enforced at all times with no bypass capability.

REQ-003 Response: 142 IP cameras cover all server rooms, corridors, loading docks, and parking areas. Footage retained for 120 days on encrypted NVR storage exceeding the 90-day requirement.

REQ-004 Response: Visitors must be pre-approved 24 hours in advance via our visitor management system. All visitors are issued temporary badges and escorted by authorized personnel at all times.

REQ-005 Response: Primary data center entrance uses a Sally port (mantrap) with interlocking doors, weight sensors, and tailgating detection. Anti-passback enforced on all controlled doors.

REQ-006 Response: Schneider Electric NetBotz environmental monitoring deployed throughout. Sensors cover temperature, humidity, water leak, and airflow. Alerts via SMS, email, and BMS integration within 30 seconds.

REQ-007 Response: All server rooms use Novec 1230 clean agent fire suppression with VESDA early detection. Systems tested semi-annually per NFPA 2001 with local fire marshal oversight.

REQ-008 Response: Dual 2MW Caterpillar diesel generators with 96-hour fuel supply on-site. Automatic transfer switches activate within 10 seconds of utility failure. Monthly load bank testing documented.

REQ-009 Response: Physical access logs retained for 3 years in our Security Information Management system. Reports can be generated within 1 hour for any audit request.

REQ-010 Response: All hardware disposal follows NIST SP 800-88 Rev. 1. We use on-site degaussing for magnetic media and physical shredding for SSDs. Certificates of destruction provided within 48 hours.

REQ-012 Response: Palo Alto PA-5450 next-generation firewalls deployed at all perimeter points. App-ID, threat prevention, URL filtering, and WildFire sandboxing active on all policies.

REQ-013 Response: Cisco Secure IPS deployed inline at all network boundaries. Signature updates hourly. Custom rules developed for Borough-specific traffic patterns.

REQ-014 Response: Cisco Umbrella DNS filtering with real-time threat intelligence. Custom block lists for known adversary infrastructure. DNS over HTTPS blocked to prevent bypass.

REQ-015 Response: All wireless networks use WPA3-Enterprise with EAP-TLS certificate authentication issued from our internal PKI. No PSK networks permitted.

REQ-016 Response: Cisco ISE network access control verifies device certificates, OS patch level, and EDR status before granting VLAN access. Non-compliant devices quarantined automatically.

REQ-017 Response: Dedicated out-of-band management network (VLAN 350) accessible only from Privileged Access Workstations via jump server. No management interfaces exposed on production VLANs.

REQ-018 Response: Cloudflare Magic Transit provides volumetric DDoS mitigation for all public IP space. Automatic activation within 3 seconds. On-premises Arbor Sightline for flow-based detection.

REQ-019 Response: NetFlow/IPFIX collected from all switches and firewalls. Data stored in Elastic cluster with 18-month hot retention. Full packet capture available for critical segments (30-day retention).

REQ-020 Response: Quarterly penetration tests conducted by NCC Group (CREST certified). Scope includes external perimeter, web applications, and social engineering. Reports delivered within 10 business days.

REQ-021 Response: All servers hardened to CIS Level 2 benchmarks using Ansible automation. Compliance validated weekly via Qualys Policy Compliance module with automated drift remediation.

REQ-022 Response: CrowdStrike Falcon deployed across all servers (Windows and Linux) and workstations. Falcon Complete MDR provides 24/7 monitoring and response.

REQ-023 Response: Critical patches applied within 7 days (exceeds 14-day requirement). High patches within 14 days. Monthly patch cycles for moderate/low with emergency out-of-cycle process documented.

REQ-024 Response: All servers use BitLocker (Windows) or LUKS (Linux) full-disk encryption. Keys escrowed in Thales Luna HSM (FIPS 140-2 Level 3, exceeding Level 2 requirement).

REQ-027 Response: Golden images rebuilt monthly using HashiCorp Packer from CIS-hardened base. Images stored in versioned repository with SHA-256 integrity verification at deployment.

REQ-028 Response: OSSEC file integrity monitoring on all critical system files, binaries, and configuration files. Alerts trigger within 60 seconds of unauthorized change.

REQ-029 Response: Windows servers use AppLocker in enforce mode. Linux servers use fapolicyd. Both configured to allow only approved binaries from golden image plus explicitly approved additions.

REQ-030 Response: Group Policy and Linux udev rules disable all USB mass storage across servers. Exceptions require CISO approval with time-limited enablement and enhanced logging.

REQ-031 Response: All certificates use 4096-bit RSA or 384-bit ECC keys (exceeds requirement). Certificate lifecycle managed via Venafi Trust Protection Platform.

REQ-032 Response: Qualys VMDR runs authenticated scans weekly against all internal systems. Critical findings auto-create Jira tickets assigned to system owners with SLA tracking.

REQ-033 Response: CrowdStrike sensor updates continuously (cloud-based). Definitions typically update within minutes of release. Fallback offline definitions update every 2 hours.

REQ-034 Response: All systems forward logs to Splunk Enterprise via syslog-TLS in real-time. Local logging disabled on production systems. Log delivery confirmed via heartbeat monitoring.

REQ-035 Response: Container images scanned at build (Snyk in CI/CD pipeline) and runtime (CrowdStrike Falcon Container). Images with critical vulnerabilities blocked from deployment via admission controller.
